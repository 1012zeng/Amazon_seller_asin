# v1.1.0 验收记录

本版新增评分/评论数 NA 保留规则，修复价格链接误读为评论数，并允许空值保存和导出。版本基线为 v1.0.0；只修改独立项目。

## 离线验证

- Node.js 24.14.0、pnpm 11.5.2；`pnpm run check` 通过。
- `pnpm test`：10 个文件、115 项通过。
- 新增 18 项测试覆盖 NA/N/A/空文本解析，评分/评论数分别为空或同时为空，已知数值门槛和价格边界，初筛重复运行与原因统计，原始字段不变。
- 使用包含价格下划线链接、无评论新品提示和正常评论链接的页面结构，同时验证 HTML 提取和浏览器提取回调，避免把 13.49 欧元读成 1,349 条评论。
- 3 种空值组合实际写入 SQLite，并通过模拟销量 yes、详情补全、Excel 读回验证：NULL 保持为 NULL，Excel 第 10、11 列显示 NA，真实评论数 0 保持为 0。
- 旧 schema 18 拒绝续跑；新库 schema 19 完整性检查通过。价格、FBA、变体、180 天和销量规则沿用原测试。
