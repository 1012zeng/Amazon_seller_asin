# Amazon Seller ASIN — 德国卖家库独立版

当前版本：**v1.0.0**。离线检查、Windows CI 和首个卖家的真实运行已完成。

从 Excel 的“卖家数据”工作表 B 列读取卖家，抓取 Amazon.de 店铺商品，保留满足前置条件、上架 **0–180 天**且通过近 7 天销量接口判断的 ASIN，补齐详情并输出 Excel。

## 本版本改变了什么

本仓库只保存独立新版。下文“旧版”指创建本项目时本地原项目的业务流程，**不是 GitHub 的上一正式版本**；原仓库初始化提交得到保留，但未上传原项目旧源码。

| 环节 | 原项目旧流程 | 本版 1.0.0 |
|---|---|---|
| 输入 | 产品链接或结果表，访问产品核验卖家 | 直接读取 Excel B 列超链接、链接文本或卖家 ID |
| 初筛 | 评论数 <300、评分 ≥3.5、价格 7.99–60.00 欧元 | 保持不变，价格两端包含 |
| 历史数据库 | 查询历史 ASIN 并排除 | 完全取消连接、健康检查和查询；不需要 MySQL |
| 配送 / 变体 | FBA、变体数非空且 ≤3 | 保持不变 |
| 上架时间 | 最长 720 天 | 0–180 天，包含第 180 天 |
| 子体近 30 天销量 | 0–365 天 ≥100；366–550 天 ≥200；551–720 天 ≥300；另有新品空销量分支 | 删除分段门槛，子体销量仅保留作展示 |
| 近 7 天销量 | 仅 0–30 天且子体销量为空时查询 | 所有满足前置条件的 0–180 天 ASIN 都查询 |
| 最终保留 | 子体销量达标可直接保留 | 必须由近 7 天销量接口返回精确 `yes` |

旧版：产品输入 → 卖家核验 → 店铺抓取 → 初筛 → 历史库排除 → SellerSprite 补全 → 配送/变体/年龄/子体销量分段 → 部分新品近 7 天销量 → 详情 → Excel。

新版：卖家 Excel → 店铺抓取 → 初筛 → SellerSprite 补全 → FBA/变体/180 天 → 全部合格候选近 7 天销量 → 通过者详情 → Excel。

上架日期缺失、非法、晚于任务基准日期，或超过 180 天均排除。子体销量为空、0 或高销量都不能跳过近 7 天判断。接口参数固定 `daily_sales_minimum=3`，窗口为运行基准日期之前的七个完整 UTC 日。仅接受 `yes` / `No`，不在客户端按七天总和或平均数替代接口判定。合法 `No` 排除；超时、缺项、日期窗口或参数回显不符会暂停，候选不会被当作销量不达标删除。

## 安装与本机配置

使用 Windows PowerShell、Node.js **24.14.0**、pnpm **11.5.2**：

```powershell
npm install --global pnpm@11.5.2
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
Copy-Item config/amazon-de.yaml config/local.yaml
```

所有命令在本仓库目录执行。也可以从其他目录调用 `run.ps1` 的完整路径，脚本会定位自己的依赖。缺少本项目依赖时直接报错，不使用父项目依赖。

`better-sqlite3@13.0.2` 包含平台预编译模块；工作区配置禁用其不必要的自动 `node-gyp` 重编译，保留 esbuild 构建许可。离线测试会实际打开 SQLite，验证本机模块可用。

`config/amazon-de.yaml` 是不含凭据的公开示例；存在 `config/local.yaml` 时默认使用它，也可通过 `--config` 指定。真实输入、输出、配置和状态不提交到 Git。已有连接约定保持为 SellerSprite `http://127.0.0.1:8012`、DE、批次 40；Amazon.de、EUR、邮编 10115；代理端口依次 7905–7908。运行前需要现有代理和 SellerSprite 服务就绪。共享代理由既有 proxy-controller 管理，本脚本不改写共享代理配置。

独立项目只包含客户端。SellerSprite 服务本身及其凭据不发布到本仓库。与原项目同时运行仍会共享代理、服务和额度，建议错开大批量任务。

## 输入与运行

B1 为表头，B2 起读取；默认工作表名称“卖家数据”。优先使用单元格实际超链接，显示名称不当作 ID。支持 Amazon.de 卖家链接中的 `me` / `seller` 参数，以及 10–20 位大写字母数字卖家 ID。不执行表格公式。空行留痕并跳过；非空非法行会在联网前报错，即便位于 `--limit` 范围之外。

重复卖家按首次出现顺序创建一次任务，所有原始行、名称和链接保存在本地 `source_seller_inputs`。`--limit` 限制唯一卖家数量，0 表示全部；多个卖家发现相同 ASIN 时仍复用原项目的运行内去重与来源记录。

```powershell
# 只检查 Excel，不访问业务服务
.\run.ps1 inspect-input --input "D:\PythonProject\深圳开发关键词检索产品\DE店铺库-中国地址.xlsx"

# 第一个有效卖家的完整链路
.\run.ps1 pipeline --input "D:\PythonProject\深圳开发关键词检索产品\DE店铺库-中国地址.xlsx" --limit 1

# 全量任务：请主动执行，单卖家验收不会自动启动全量
.\run.ps1 pipeline --input "D:\PythonProject\深圳开发关键词检索产品\DE店铺库-中国地址.xlsx"

.\run.ps1 status --run <运行ID>
.\run.ps1 pipeline --resume <运行ID>
```

支持独立阶段命令 `stores`、`prefilter`、`enrich`、`filter`、`sales-7d`、`detail`、`export`，均使用 `--run <运行ID>`。没有卖家产品核验或历史筛选命令。

退出码：0 完成；1 启动、配置或阶段错误；2 部分抓取/服务暂停，需查看状态；130 用户中断。服务返回失败时按现有重试逻辑处理，不能通过降低校验绕过。先查看 `status` 和事件日志，修复服务后使用同一运行 ID 续跑；不要并发启动两个进程写同一任务。

## 输出、续跑和隔离

输出位于本仓库 `output/runs/<运行ID>/`：

- `state.sqlite`：schema 18，原始抓取、输入审计、各阶段候选、销量与详情任务。
- `events.jsonl` / `summary.json`：阶段数量、排除原因、重试、失败与完整性证据。
- `exports/*.xlsx`：最终保留产品，19 列、5 个工作表。

工作表为 `产品数据`、`0-30天`、`31-365天`、`366-550天`、`551-720天`。保留旧表名兼容既有使用习惯；本版 `31-365天` 实际只有 31–180 天，最后两表仅有表头。完整表每个 ASIN 一行，并且恰好进入一个年龄分组。第 7 列为“近7天是否日均3单+”，最终保留行均为 `yes`；子体销量原值仍显示。

运行记录工作流 ID、代码 SHA-256 指纹、有效配置哈希、输入文件哈希、UTC 基准日期、Git 提交和版本。续跑拒绝输入、配置或业务代码变化，不允许同时指定新的 `--input`、`--config`、`--limit`。文档与测试改动不改变运行代码指纹。业务代码升级后创建新任务；不会迁移或续跑原项目 schema 17 或更早任务。

本项目是当前实现的独立副本，不在运行时导入父项目代码。源码、配置、依赖、数据库、输出和运行索引均独立；未来改动只提交本仓库。父项目代码不会自动同步进来。

分页仍按原逻辑：首个页面出现数字末页时冻结范围并遍历；没有数字末页时沿 Next 链并应用原兜底上限。重复 ASIN、重复页面、途中页数变化和抓取不完整会记录。**分页流程完成不等于已证明卖家全部库存都被 Amazon 搜索结果展示。** 未解决的必要任务不能标记完整成功；抓取部分完成时结果必须标记 partial。

## 本版真实验收结果

首个卖家实际抓取 367 页、5,872 条出现记录、2,515 个不同 ASIN。初筛保留 3 个 ASIN，SellerSprite 两轮均返回 not_found，最终产品数 **0**，Excel 五表仅有表头。没有触发实际 ASIN 的近 7 天销量和详情请求；这两个分支只完成离线测试，不能宣称真实数据接口验收通过。分页存在重复页面等警告，抓取结果不等于已证明卖家全部库存数量。
